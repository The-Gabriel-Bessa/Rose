# Rose

Projeto de estudo e documentação do OpenCode - agente de código AI open source.

## Estrutura

```
Rose/
├── .opencode/              # Configuração do OpenCode para este projeto
├── docs/
│   ├── opencode-api/       # Documentação da API REST do servidor
│   ├── opencode-config/    # Schema de configuração (opencode.json)
│   ├── opencode-server/    # Arquitetura do servidor e endpoints
│   ├── opencode-sdk/       # SDK JS/TS e uso programático
│   └── opencode-context/   # Limites de contexto e comportamento
├── AGENTS.md               # Instruções para o agente OpenCode
└── opencode.json           # Configuração do projeto
```
